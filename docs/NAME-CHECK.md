# Name check: "Nestwright"

> **Not legal clearance.** This is a first look from public searches, done on 2026-11-14.
> It does not replace a search by a trademark attorney or agent, and finding nothing in a
> database does not mean the name is free to register or use. The owner decides whether to
> file and where.

## Classes that matter

| Nice class | Covers | Why it applies |
| --- | --- | --- |
| 9 | Downloadable game software, recorded software | The game itself on Steam |
| 41 | Entertainment services, providing online games | Store page, events, Next Fest |
| 28 (optional) | Games and playthings | Only if physical merch ever happens |

## Search the registers yourself

Type `Nestwright` and also try `Nest Wright`, `Nestright`, `Nestrite` (similar-sounding marks count).

| Register | Link | Notes |

Filter each register to classes 9 and 41 and read both live and pending applications.

## What turned up (2026-11-14)

- **WIPO Global Brand Database**, brand name containing `nestwright`: **no results**. The database
  draws on USPTO, EUIPO, INPI Portugal and the Madrid system among others, so this is the widest
  single check, but it can lag new filings by weeks.
- **Web search** (game stores, app stores, itch.io, general): **no game, app or company** called
  Nestwright apart from the one below.
- **nestwright.com is taken by a live product.** Registered 2026-07-24 through Cloudflare. It is an
  AI service for real-estate listing agents ("the AI that runs your listing prep"): different goods
  and services from a game, but the same word, also around homes, and a sign-up flow that suggests a
  company that may file a mark. Check USPTO and EUIPO for a pending application under classes 35/42
  in its name before committing to the name; a later filing by them in class 9 or 41 is a risk.
- **Domains** (whois, 2026-11-14): `nestwright.net`, `nestwright.io` and `nestwright.pt` were
  unregistered. `.games` and `.app` could not be read from whois; check at a registrar.
- **Handles**: `github.com/nestwright` and `x.com/nestwright` returned 404 (probably free; X sometimes
  hides suspended accounts). `reddit.com/r/nestwright` answered 200, which Reddit also does for an
  empty or banned subreddit; check it in a browser.

## Before announcing the name

- [ ] **(owner)** Run the searches above in TMview, USPTO and INPI, classes 9 and 41.
- [ ] **(owner)** Decide on the nestwright.com overlap; consider a short paid clearance opinion.
- [ ] **(owner)** If keeping the name, file at least an EU trade mark (EUIPO) in classes 9 and 41
      before the Coming Soon page goes public; INPI only if a Portugal-only mark is enough.
- [ ] **(owner)** Register a domain and the handles you will actually use.
